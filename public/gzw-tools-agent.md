# GZW Tools Browser Guide

GZW Tools is a community-made browser companion for Gray Zone Warfare. It is not affiliated with M.A.G. Studios. Use the linked pages as read-only references; reputation, task progress, and loadouts that users save are stored in their browser.

## Find information

- [Overview](https://gzw-tools.vercel.app/): vendor reputation summary and shortcuts to common tools.
- [Missions](https://gzw-tools.vercel.app/missions): browse tasks, filter by vendor or location, and track completion locally.
- [Ammunition](https://gzw-tools.vercel.app/ammo): compare rounds by caliber and armor penetration.
- [Weapons](https://gzw-tools.vercel.app/weapons): search weapon names, calibers, and statistics.
- [Armor](https://gzw-tools.vercel.app/armor): compare vests, helmets, and protection classes.
- [Keys](https://gzw-tools.vercel.app/keys): look up keys, locations, and their usage.
- [Backpacks](https://gzw-tools.vercel.app/backpacks): compare storage gear.
- [Loadouts](https://gzw-tools.vercel.app/loadouts): build equipment plans in the browser.
- [API documentation](https://gzw-tools.vercel.app/api-docs): read the public GZW Data API contract before making API requests.

## Use responsibly

- Prefer the page or API documentation for the exact field definitions; do not infer game mechanics from a display label alone.
- Treat game data as community reference data, not official M.A.G. Studios information.
- Do not claim that a locally saved plan has been synced to an account or server.
